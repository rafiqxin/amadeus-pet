# Amadeus Android reference UI assets

The helper `scripts/sync-amadeus-ui.mjs` obtains selected UI artwork from
`rafiqxin/Amadeus` (fork/reference repository; upstream `Yink/Amadeus`).

The reference repository declares GNU GPL v3.0 for the project, and its README
separately credits DavixxaYT for assets. The MIT declaration in this desktop
project does not relicense downloaded third-party artwork.

Synchronized files:

- bg1.png
- amadeus_icon_smaller.png
- subtitle_frame_big.png
- logo39.png
- connect_unselect.png / connect_select.png
- cancel_unselect.png / cancel_select.png

The files are kept under `public/Resources/amadeus-reference/` and are not
mixed into the existing Live2D model directories. Confirm applicable upstream
asset rights and attribution requirements before redistributing packaged builds.
